# FocusForge

FocusForge is a productivity and learning platform designed to help students stay focused and organized.
It provides focus sessions, task management, quests, XP, badges, and progress tracking.
The platform includes a student frontend and an administrator dashboard.
The backend is built using FastAPI and Python.
The frontend is developed using HTML, CSS, and JavaScript.
The system uses a database to store users, tasks, learning content, and progress.
Administrators can manage subjects, topics, lessons, and mock tests.
Students can follow learning roadmaps and monitor their analytics.
FocusForge is designed to make learning more engaging through gamification.
